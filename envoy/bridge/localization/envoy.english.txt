# Envoy Framework - every line the player can read, English.
#
# English is the source language: this file is written by hand, the others are
# translated from it. The lines of the log are not missing but live in a section
# of their own, envoy.log.english.txt, merged with this one when the tables are
# built: the log is translated like everything else, and a section per subject
# keeps one file from holding everything.
#
# One "$KEY<tab>text" line each; \n in a value becomes a line break. Lines
# that do not start with $ are notes and are dropped on the way out.
#
# tools/build-localization.py turns this file into two things: the baseline
# compiled into the plugin (src/core/LocStrings.h) and the UTF-16 file the game
# reads (Interface/Translations/Envoy_english.txt). Edit here, never there.

$ENVOY_LOG_TITLE	Bridge log
