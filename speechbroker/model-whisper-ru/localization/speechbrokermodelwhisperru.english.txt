# Speech Broker - Voice Model - Whisper RU: every line this mod puts out, English.
#
# The shim has no window and no notices: all of this is the log. Two of them read
# it - our own file next to the adapter's, and the adapter's own log, where the
# same line arrives as the key and its arguments rather than as a sentence,
# because the adapter has no table of ours and substitutes nothing.
#
# The child renders nothing at all. It sends a key out of this file and its
# arguments up a pipe, which is why a message added here needs no edit anywhere
# else - not in the shim, and certainly not in the adapter.
#
# Placeholders are numbered, {0} and {1} rather than a bare {}, because another
# language puts the words in another order. A wrong number of them does not
# silence the line: the placeholder is left standing and the rest still reads.
