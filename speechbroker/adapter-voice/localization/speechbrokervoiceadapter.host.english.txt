# SpeechBrokerVoiceAdapter - the dispatch half: the host, the registry, the model
# threads. English. A FRAGMENT: the integrator merges it into
# localization/speechbrokervoiceadapter.english.txt and regenerates src/LocStrings.h.
#
# Same format as the main table: key<TAB>text, numbered placeholders {0} {1},
# because another language puts the words in another order. A wrong number of them
# does not silence the line - the adapter falls back to printing the bare key.
#
# What is NOT translated here, deliberately, because it is data and not a message:
# the id of a model, the name of a contract function, a status code, a fault code
# and the name of a field. They arrive as arguments inside these lines.
